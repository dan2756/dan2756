## ReelForge

ReelForge is a home base for a short-form video channel. It tracks followers, views and likes hour by hour on TikTok, YouTube, Instagram and X, and scores every video against your typical one so you can see what's working.

Posting stays manual, just faster. Pick a finished video and ReelForge copies each platform's caption, shows you the file and opens the upload page. No API keys or developer accounts needed.

## Small tools

Command-line tools I wrote in Go because I kept needing them:

- [**portkill**](https://github.com/dan2756/PortReaper): see what's holding a port and stop it
- [**stale-branches**](https://github.com/dan2756/BranchBroom): find merged and months-old Git branches and clear them out
- [**flaky**](https://github.com/dan2756/FlakeRadar): run a test over and over to see how flaky it really is
- [**todo-age**](https://github.com/dan2756/TodoFossil): list every TODO by how long it's been sitting in the code
- [**jsonshape**](https://github.com/dan2756/JSONSilhouette): get the shape of unfamiliar JSON without scrolling through it

The rest are in [my repositories](https://github.com/dan2756?tab=repositories).
